Cómo usar el demo

Controles táctiles

  • • Pulsa INICIAR y permite cámara + micrófono.
  • • Usa REC para grabar, Cal CERR/ABI para calibrar.
  • • Pulsa 🥁 para abrir Beat IA y generar un beat.
  • • El botón 🎧 activa modo calentamiento con metrónomo y afinador.

Gestos de mano

  • ✊ Puño cerrado + bajar = grabar/detener
  • ✋ Palma abierta = detener todo
  • 👍 Pulgar arriba = play/pause beat
  • ☝ Anular extendido = abrir/cerrar Beat IA
  • 👌 Pulgar+índice círculo = generar beat
  • ✌ Índice+medio = cambiar estilo de beat

Nota: en móviles, el navegador requiere HTTPS para acceder a cámara y micrófono. Si el demo local no funciona en tu celular, usa Tailscale o un túnel seguro.
