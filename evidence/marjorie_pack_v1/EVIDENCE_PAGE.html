Resumen

Metodología operativa de segmentación contextual, continuidad y control de deriva conversacional. Estructura cada interacción en fases BASE → CENTRO → ACCIÓN (más EVIDENCIA / VEREDICTO), de modo que el asistente mantiene el objetivo, evita loops y genera salidas más organizadas. Diseñada para mejorar la colaboración a largo plazo con modelos conversacionales y codificada en sistemas internos (MEMO, GO modes, handoff).

Las 3 líneas del protocolo

📐 BASE
¿Qué estoy viendo de verdad? Realidad material: runtime, archivo, endpoint, sesión. Evita alucinación romántica.
🎯 CENTRO
¿Cuál es la señal viva? Reglas, identidad, memoria, prioridades, relaciones entre piezas. Filter + focus.
⚡ ACCIÓN
¿Qué hacer ahora, sin humo? Decisión, prioridad, bloqueo, siguiente paso o no-acción justificada.

Beneficios observados

✓ Continuidad mejorada entre sesiones
✓ Eliminación de loops y divagaciones
✓ Decisiones claras + evidencia trazable
✓ Reducción significativa de tokens
✓ Reproducibilidad de colaboración
✓ Salidas estructuradas y auditables
