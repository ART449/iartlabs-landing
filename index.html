Metodología

La Colmena

Un framework operativo para sistemas multi-agente donde cada capa tiene métricas, gates y contratos explícitos.

∑H

EDIS

Entropy Dynamics Instability Score. Detecta anomalías en outputs de LLMs usando entropía de Shannon.

EDIS = (H_dyn − H_base) / H_base × 100
GO

GO Modes

Gates deterministas. Sin ambigüedad, sin "depende del experto". La métrica decide.

<15% → GO_NORMAL

15-30% → GO_AUDITORIA

30-50% → GO_CTO

>50% → GO_NO_APPLY

{}

Nahuallatolli

Protocolo JSON estricto para comunicación Agent-to-Agent. Previene manipulación por texto libre.

"go_mode": ...,
